# caminocoachdave.com

Static hub site for Dave Hall (Camino Coach Dave). One page, five doors: Book, Coaching, Retreats, Newsletter, Stay.

- `index.html` is the whole site (built for the claude.ai artifact wrapper; for Vercel, prepend the doctype/head below or deploy as-is with a wrapper).
- `assets/` holds the photos and the CaminoLife logo, all taken from Dave's own live sites.
- `vercel.json` maps the July 24 spoke URLs (/book etc.) to anchors.
